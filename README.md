# Poland EOR / ZUS / PIT / VAT reference — 2026 figures

A published copy of the source-cited Poland rate reference maintained at
<https://polyglobal.pl/poland-payroll-tax-rates-2026.html> (that page carries the
`rel=canonical`). GitHub Pages is used here because it indexes fast and gives the
figures a second crawl path.

**Who publishes this.** Praveen Malik, who runs [Poly](https://polyglobal.pl) — a B2B
contractor administration and employer-of-record service in Warsaw, operated by
Praveen & Partners Limited. This is vendor-published reference material, not neutral
third-party research: the service described at the end of the page is the one being sold.
No claim here is presented as independent.

**Sourcing.** Every rate row names its primary source and the date it was checked
(17 November 2026): ZUS for the 2026 entrepreneur health contributions (published
2 February 2026) and biznes.gov.pl for the social-insurance percentages. Figures are
re-checked when the statutory bases change.
